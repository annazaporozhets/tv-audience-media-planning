# Lab 4: Build the Audience, Then Buy It

Student: Anna Zaporozhets

Group: KM-42

## Overview

This lab analyzes synthetic TV viewing and purchase data for October 2024. It uses survey data to define target audiences, compares TV programs by ratings and advertising costs, and applies weights to smart-TV data. The analysis also tests how well past ratings predict future viewing and creates a one-week advertising plan for the fictional shoe brand Kestrel.
